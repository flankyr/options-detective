# v1.11.0 — Hygiene, safety, and the chain archive

First release of the v2 roadmap (`docs/ROADMAP-v2.md`, Phase 0). No change to
what the app computes; everything here is about being safe to build on.

## New

- **Option chain archive.** The backend records every watched symbol's full
  chain once per trading day after the close, as parquet under the data
  directory. Backtesting and calibration (v2.0) will read these files.
  Settings → Data: enable toggle, extra symbols, snapshot now, coverage table.
  Default watchlist SPY, QQQ, IWM, AAPL, MSFT, NVDA, TSLA, AMZN plus every
  symbol with an open journal trade.

## Fixed

- **Network exposure.** The Express backend now binds `127.0.0.1` only and
  answers CORS solely for the renderer's own origins. Previously it listened on
  every interface with wildcard CORS, so other LAN devices and any web page
  could call `/detect` and `/calculate`.
- **Fresh installs could not fetch market data**: `yfinance` was missing from
  `backend/math/requirements.txt`.
- Node tests no longer show 21 red tests when the Python venv is absent; the
  engine suites skip with the setup command instead (CI forbids the skip).

## Changed

- Packages renamed `option-obelisk-*`; the renderer bridge is
  `window.optionObelisk`. The Electron `appId` is unchanged so existing
  installs upgrade in place.
- GitHub Actions CI on Windows: pytest, node tests against the real engine,
  tsc, vite build. ESLint/Prettier/ruff/black configs added; lint is advisory
  until the one-time format commit.
- `LaunchCodes.txt` replaced by `docs/RELEASING.md`.

## Known

- Installer still unsigned (Phase 7). `pyarrow` + `pandas` grow the
  PyInstaller bundle by roughly 60 MB.
