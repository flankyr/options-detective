# v2.0.0 — Simulator

Phase 5 of `docs/ROADMAP-v2.md`. Closes A14. The first release where the
app can test its own claims: every number the screener shows can now be
checked against history on the Research tab. Method notes:
`docs/algorithms/simulator.md`.

## New

- **Point-in-time backtester** over archived chains with daily marks,
  management rules (profit target, stop, DTE exit, expiry settlement), the
  Phase 4 cost model, and no look-ahead by construction.
- **Strategy plug-in API** with four built-ins: the optimizer itself and three
  model-free yardsticks (16Δ strangle, VRP-gated put spread, buy-and-hold).
- **Metrics with uncertainty**: Sharpe carries a 90% bootstrap interval; the
  UI says plainly when it includes zero.
- **Calibration**: predicted POP buckets vs realized win rate with Brier
  scores, EV bias and slope.
- **Walk-forward** parameter selection and a forecaster bake-off.
- **Research tab**: pick a strategy, edit its parameters as JSON, choose
  symbol and dates, run, read the curve, metrics, calibration and trade table,
  export trades as CSV. Runs are saved under the data directory.
- `od-math simsvc`, `/research/strategies|runs|backtest|walkforward|status`.

## Changed

- `DataService.get_chain(..., enrich=False)` skips the smile fit for marking
  days; `forecast(..., asof=)` truncates history for backtests.

## Not in this release

- The paper-trading sandbox still runs on the v1 marking path; its switch to
  the v2 engine and the archive replay mode move to v2.1.
- Transparency UI (mode switch, "why this number" drawer) is v2.1.

## Tests

8 pytest for the simulator (accounting identity, no look-ahead, forecast
engagement, buy-and-hold tracks the underlying, runner envelopes, metrics
and calibration units, walk-forward) over a synthetic 90-day archive;
3 node tests for the routes. 1,397 pytest / 141 node green.
